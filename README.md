# notes

Notes and write-ups from my cybersecurity self-study and lab sessions, covering various topics. Written in Obsidian.

## structure

| folder         | what goes in it                            |
| -------------- | ------------------------------------------ |
| `writeups/`    | how I solved specific labs and challenges. |
| `knowledge/`   | notes on concepts, protocols, tools, etc.  |
| `attachments/` | screenshots and images used in notes       |

Write-ups link to the knowledge notes they use, so each concept note collects every lab where it came up.
